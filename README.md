# LPBrower

Trình quản lý hồ sơ trình duyệt nhân Chromium độc lập (Windows & macOS).

## Cài đặt & Sử dụng

Tải bộ cài đặt mới nhất tại mục [Releases](https://github.com/yamitnb/LPBrower/releases):

- **Windows (x64)**: `LPBrower_Setup_x64.exe`, `LPBrower_Setup_x64.msi`, hoặc bản chạy trực tiếp `LPBrower.exe`.
- **macOS (Apple Silicon)**: `LPBrower_Setup_macOS_arm64.dmg`.
